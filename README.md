This is a **React-based Note Application** that allows users to **create, edit, and delete notes** in an interactive and user-friendly interface. Notes are added through a **popup form**, making the experience clean and focused.

The app supports **real-time editing,** where existing notes can be updated with pre-filled data, and includes features such as **auto-focus on input fields**, smooth form toggling, and instant state updates using React hooks.

This project is built to practice **React state management, CRUD operations, conditional rendering,** and **form handling** in a practical way.
